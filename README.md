# Mission Control

Aplicação web full-stack para gestão de missões, robôs e operadores.

## Objetivo

Rever o desenvolvimento de uma aplicação PERN completa, desde a modelação e criação da base de dados até à API REST e à interface.

## Tecnologias previstas

- PostgreSQL
- Express
- React
- Node.js
- Sequelize
- Axios
- CSS Modules
